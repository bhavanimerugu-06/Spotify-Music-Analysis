
# Spotify Music Analysis and Visualization

## Project Overview
This project analyzes Spotify music data using Python and data analytics techniques. It explores song popularity, artists, genres and audio features through interactive visualizations.

## Objectives
- Analyze song popularity.
- Identify popular songs and music genres.
- Study danceability and energy.
- Explore relationships between audio features.
- Present insights through an interactive dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Matplotlib
- Seaborn

## Dataset
Spotify Tracks Dataset from Kaggle:
https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset

## Data Preprocessing
- Removed unnecessary index columns.
- Removed duplicate records.
- Handled missing values in important columns.
- Converted numerical columns into numeric format.

## Visualizations
- Top 10 popular songs.
- Genre distribution.
- Energy distribution.
- Danceability vs popularity.
- Audio features correlation heatmap.

## How to Run

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the dashboard:

   python -m streamlit run app.py
